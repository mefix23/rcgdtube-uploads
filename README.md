# rcgdtube-uploads

Видео, которые админы добавили на сайт [РКГДTUBE](https://mefix23.github.io/rcgdtube/) вручную.

- `uploads.json` — добавленные (`videos`) и скрытые (`hidden`) видео. Меняется через страницу `upload.html`.
- `config.json` — зашифрованные данные для входа по ключам. Руками не менять.
